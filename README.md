Checkout E-commerce
Projeto em JavaSCript que simula um checkout de e-commerce, calculando os valores de compras e aplicando cupons de desconto.

Funcionalidades
Cálculos do subtotal e contagem de itens.
Aplicação de cupons de desconto
Finalização da compra.

Como executar
Instale o Node.js e execute no terminal:
node checkout.js

Branches
main: versão principal.
develop: integração das funcionalidades.
feature/carrinho-laco: funções do carrinho.
feature/validacao-cupom: validação dos cupons.

Uso do Git
O Git permite desenvolver funcionalidades em branches separadas, registrar alterações em commits e integrar os códigos por meio de merge, evitando que alterações sobrescrevam o trabalho de outros desenvolvedores.
